# エラー修正スキル

エラーメッセージを貼り付けて「直して」と指示されたときに適用する。

## 手順

1. **エラーメッセージを解析** — 種類と発生箇所を特定
2. **原因を特定** — コードを読んで根本原因を調査
3. **修正を実施** — [docs/開発規約.md](../../../docs/開発規約.md) に違反しない形で修正
4. **検証** — `pnpm verify` で全チェックがパスすることを確認

## よくあるエラーと対処

- **型エラー**: `pnpm typecheck` で確認。`any` で逃げない
- **lint エラー**: `pnpm lint:fix` で自動修正
- **Vite のビルドエラー**: `pnpm build` で再現し、import パス（`@/` エイリアス）と `base` 設定を確認
- **Canvas / 画像デコード**: ブラウザ差異の可能性があるため、Playwright で実ブラウザ再現を試す

## ルール

- 根本原因を修正する（場当たり的な回避策は避ける）
- 修正後は必ず `pnpm verify` を実行する
