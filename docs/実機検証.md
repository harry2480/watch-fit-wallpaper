# 実機検証

要件定義 18.5（実機テスト）と 19章（Apple Watch 実機検証）の手順と結果を記録する。
iOS の共有シートや写真保存、Apple Watch での表示は、ブラウザのエミュレーションだけでは合格にしない（18.5）。

## 1. 自動テストで確認済みの範囲

2026-11-17 時点。CI（`.github/workflows/ci.yml`）で PR ごとに実行している。

| 環境 | 実行方法 | 確認した内容 |
|---|---|---|
| Chromium（macOS Chrome 相当） | `pnpm test:e2e`（project: chromium） | 18.4 の一連の操作、PNG / JPEG のダウンロードと解像度、EXIF の向き、通信の監視（CSP あり・なし）、CSP 違反なし |
| WebKit 27.2・iPhone 15 エミュレーション（iPhone Safari 相当） | `pnpm test:e2e`（project: iphone-safari） | タッチのドラッグ・ピンチ（Pointer Events を合成）、共有シートへの受け渡し（スタブ）と解像度、共有の権限切れからの再共有、EXIF の向き、CSP 違反なし・外部通信なし |
| WebKit 27.2・デスクトップ（macOS Safari 相当） | `pnpm test:e2e`（project: desktop-safari） | 同上 |

## 2. 実機での確認手順（ブラウザ）

公開 URL: https://harry2480.github.io/watch-fit-wallpaper/

### 対象

| 区分 | 環境 |
|---|---|
| 必須 | iPhone Safari、macOS Safari、macOS Chrome |
| 可能なら | Android Chrome、Windows Chrome、Windows Edge、Firefox |

### 手順

1. 公開 URL を開き、ヘッダー・アップロード領域・モデル選択が表示されることを確認する。
2. 写真ライブラリ（PC ではファイル選択とドラッグ＆ドロップの両方）から画像を選ぶ。HEIC の写真も試す。
3. モデルを選び、プレビューの縦横比と「保存サイズ」が変わることを確認する。
4. ドラッグ・ピンチ（PC ではホイール）・ズームスライダー・方向ボタンで調整する。ページがスクロールしたり拡大したりしないこと、プレビューの外では通常どおりスクロールできることを確認する。
5. Cover と Contain を切り替え、構図が中央に戻らないこと、Cover で余白が出ないことを確認する。
6. 背景色を変え、Contain の余白に反映されることを確認する。
7. PNG と JPEG で保存する。iPhone では共有シートが開き、「画像を保存」で写真アプリに保存されること、キャンセルしてもエラーが出ないことを確認する。
8. 保存した画像の解像度が「保存サイズ」と一致し、プレビューと同じ構図であることを確認する。
9. 対応していないファイル（PDF など）を選んだときに日本語のエラーが出て、選び直せることを確認する。

| macOS Safari | 未実施 | — | — |
| macOS Chrome | 未実施 | — | — |

## 3. Apple Watch 実機での表示検証（19章）

### テスト画像

`docs/verification/images/` にある（`node scripts/generate-verification-images.mjs` で再生成できる）。人物の写真の代わりにシルエットを使っている。

| ファイル | 内容 | 主に見る点 |
|---|---|---|
| `01-center-subject.png` | 中央に人物（シルエット）、中央に十字線 | 中央位置の維持、時計表示との重なり |
| `02-edge-subject.png` | 右下に被写体 | 端の被写体が切れないか |
| `03-landscape.png` | 横長、左右の端に目印 | 左右のトリミング |
| `04-portrait.png` | 縦長、上下の端に目印 | 上下のトリミング |
| `05-edge-markers.png` | 四辺に色の違う目印（上: 赤、右: 緑、下: 青、左: 黄） | どの辺がどれだけ切れるか、追加ズームの有無 |
| `06-black-white-frame.png` | 黒背景に白い枠 | 余白が維持されるか（Contain） |
| `07-grid.png` | 100px ごとの格子 | 位置ずれ・拡大率 |

### 手順

1. WatchFit でテスト画像を読み込み、検証する Apple Watch のモデルを選ぶ。
2. 次の 2 通りで保存する。
   - Cover・中央配置（フィット）のまま
   - Contain・中央配置（フィット）のまま
3. 保存した画像を写真アプリに保存し、Watch アプリで「写真」文字盤に設定する。
4. 文字盤のレイアウト（時計の位置・スタイル）を変えながら、下表の項目を確認する。プレビューと見比べられるよう、Apple Watch の画面を撮影して記録する。

### 確認項目（19.3）

- 中央位置が維持されるか
- 上下左右がトリミングされるか（どの辺が何 px 程度か）
- watchOS による追加ズームがあるか
- Contain の余白が維持されるか
- 時計表示が被写体に重なるか
- モデル間で差があるか
- 文字盤のレイアウト間で差があるか

### 結果

| モデル | watchOS | 文字盤レイアウト | テスト画像 | 結果（上記の確認項目） | 確認日 |
|---|---|---|---|---|---|
| 未実施 | — | — | — | — | — |

### 差異が見つかった場合

推測で補正しない（19.4）。モデル別・文字盤レイアウト別・watchOS バージョン別に差異を記録し、補正機能が必要かどうかを判断する Issue を起票する。補正を入れる場合は、ユーザーが無効化できるようにする。

## 4. 既知の制限

- 本アプリが保証するのは「プレビューと保存画像の構図の一致」まで。Apple Watch 実機での表示の完全な一致は保証しない（1.5、22章）。
- 上記の実機検証が未実施の項目は、結果が記録されるまで動作を保証しない。
